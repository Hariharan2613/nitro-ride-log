# Premium Bike Service & Maintenance Tracker

## Overview
Build a complete multi-page motorcycle service experience with a dark luxury automotive aesthetic, premium imagery, fluid animation, and a usable service-tracking dashboard.

## Experience
- Create a shared sticky glass navigation and restrained footer across Home, About Us, Bike Brands, Bike Pricing, Service Tracker, and Contact.
- Lead with a full-screen sports-bike image, the supplied headline, two calls to action, and an infinite POWER → PERFORMANCE → PRECISION → SPEED → RELIABILITY word sequence.
- Use charcoal and deep-blue surfaces, neon-blue accents, crisp typography, glass panels, fine technical linework, and subtle glow rather than generic gradients.
- Generate cohesive sports-motorcycle imagery for the hero and supporting editorial sections.

## Pages
- **Home:** Immersive hero, animated metrics, feature overview, service workflow, bike visual, and dashboard preview.
- **About Us:** Brand story, mission, operating principles, and rider-focused statistics.
- **Bike Brands:** Ten requested manufacturers with stylized wordmarks, popular models, starting prices, filtering, and responsive glass cards.
- **Bike Pricing:** Clear service tiers, inclusions, comparison details, and booking calls to action.
- **Service Tracker:** Add-bike flow, mileage update, maintenance timeline, reminders, uploaded record management, progress cards, and interactive analytics charts using polished sample data.
- **Contact:** Contact form, service-center information, support options, and newsletter signup.

## Motion and Interaction
- Use Framer Motion for page transitions, scroll reveals, counters, the rotating hero words, card glow, and subtle image parallax.
- Respect reduced-motion preferences and keep all controls keyboard accessible.
- Add useful feedback for forms and dashboard actions without requiring account setup or persistent storage.

## Technical Details
- Keep TanStack Router and create a dedicated route for every requested page, each with unique social and search metadata.
- Add reusable layout, motion, brand, pricing, and dashboard components.
- Extend the Tailwind v4 token system in the global stylesheet; use semantic colors and typography throughout.
- Use a lightweight charting library only if already suitable; otherwise build responsive SVG charts locally.
- Verify desktop and mobile rendering, navigation, forms, dashboard actions, animations, and console health in the running preview.
